01

Diseño Arquitectónico Desacoplado

Implementación modular distribuida en tres capas de responsabilidad estricta.

Capa Presentación

Frontend Autónomo

Diseñado con JavaScript ES6+ puro (Vanilla) y CSS estructural modular. Elimina la sobrecarga de frameworks externos de cara al rendimiento.

HTML5 Dinámico

Vistas dinámicas optimizadas con soporte para temas variables y catálogo responsive.

Componentes UI

Controles aislados como producto-card.js y carrito.js para evitar colisiones de lógica.

Lógica cliente Modular / ES6+
Capa Negocio

API Web Backend

Motor REST construido sobre ASP.NET Core que valida identidades, procesa los impuestos transaccionales y rige las operaciones comerciales.

Controllers & Services

Puntos de acceso REST API protegidos y middleware para el control de errores transaccionales.

Dapper & EF Core

Híbrido de persistencia para consultas rápidas optimizadas y mapeo de entidades relacionales.

Lógica servidor C# / .NET Core
Capa Datos

Base de Datos Física

Motor de datos relacional robusto configurado para asegurar la atomicidad y consistencia de las compras mediante transacciones ACID.

Procedimientos Almacenados

Consultas precompiladas que mitigan riesgos de inyección y mejoran los tiempos de respuesta del stock.

Constraints de Integridad

Reglas estrictas de llaves foráneas para evitar pedidos huérfanos y inconsistencias de stock.

04

Script de Inicialización de Persistencia

Inspecciona el orden de eliminación en cascada y carga de catálogos maestros de la base de datos real (basado en la captura del SQL Server).

SeedData.sql
SQL Server Script

Para evitar conflictos por claves foráneas (FK), el script SQL limpia la base de datos eliminando en un orden inverso estricto, desde las tablas dependientes (Movimientos) hasta las tablas maestras (Roles, Marcas).

Reseteo de Identidades

Utiliza la sentencia DBCC CHECKIDENT para reiniciar todos los contadores de identificación autoincrementales a cero.

USE LeandroBaterias;
GO

-- Eliminar datos existentes (en orden correcto por FK)
DELETE FROM MovimientosInventario;
DELETE FROM AlertasStock;
DELETE FROM FacturasDetalle;
DELETE FROM Facturas;
DELETE FROM PagosDetalle;
DELETE FROM Pagos;
DELETE FROM LogicasHistorial;
DELETE FROM Logicas;
DELETE FROM DetallesPedido;
DELETE FROM Pedidos;
DELETE FROM Clientes;
DELETE FROM Baterias;
DELETE FROM Categorias;
DELETE FROM Marcas;

-- Reseter identity contadores
DBCC CHECKIDENT ('Marcas', RESEED, 0);
DBCC CHECKIDENT ('Categorias', RESEED, 0);
DBCC CHECKIDENT ('Baterias', RESEED, 0);
